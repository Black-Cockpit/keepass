# Tests

The tests of the collection are documented in [Testing](../docs/development/testing.md).

- **Run everything:** `make run_tests` from the repository root.
- **Unit and module tests:** `tests/unit/`, run by `make run_unit_tests`.
- **Integration tests:** `tests/integration/`, run by `make run_integration_tests`.
- **Sanity ignore file:** `tests/sanity/`, used by `make run_sanity_tests`.
